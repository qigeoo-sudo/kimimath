分支覆盖的局部模型：x = a + t²

为了把结构看清，动画把分支点平移到 a = 0，于是局部模型变成 x = t²。第一部分展示底面小圆盘的原像怎样从“两块”合并为“一块”；第二部分展示绕分支点一圈时，两个原像为什么恰好互换。

一　小圆盘的两个原像怎样在分支点处合并

蓝色圆盘是 x 平面中的小邻域 D；紫色区域是它在 t 平面中的精确原像：{ t : |t² − c| ≤ ρ }。远离分支点时它近似两个小圆盘；靠近分支点时这种近似失效，精确原像会被拉长并在 t = 0 接触。

紫色区域变成“水滴形”不是动画失真，而是平方映射的精确结果。远离分支点时，平方映射在 +√c 与 −√c 附近近似线性，所以两个原像区域近似圆盘；越靠近 t = 0，导数 2t 越小，逆映射的拉伸越强，两个区域便朝原点伸长。底面圆盘刚好经过分支点时，精确原像在 t = 0 接触；圆心到达分支点时，条件 |t²| ≤ ρ 才重新化成一个真正的圆盘 |t| ≤ √ρ。虚线圆显示远离分支点时的局部圆盘近似。
