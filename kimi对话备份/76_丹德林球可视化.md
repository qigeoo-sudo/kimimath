## Dandelin Spheres & Conic Sections — 丹德林球与圆锥曲线

这是一个 **3D 交互式可视化教学演示**，基于 **Three.js** 构建，展示丹德林球（Dandelin Spheres）与圆锥曲线（椭圆、抛物线、双曲线）之间的几何关系。

### 核心功能

| 特性 | 说明 |
| --- | --- |

| **3D 圆锥模型** | 展示正圆锥（顶点向下）及对顶圆锥（双曲线时自动出现） |
| --- | --- |
| **丹德林球** | 红色球（上球）和蓝色球（下球），根据截面角度自动计算球心位置和半径 |
| **截面平面** | 可旋转的截面平面，与圆锥相交形成圆锥曲线 |
| **焦点标注** | 自动计算并标注 F₁（红焦点）和 F₂（蓝焦点） |
| **切圆** | 显示丹德林球与圆锥的切圆（T₁、T₂） |
| **母线与切点** | 动态展示点 P 在圆锥曲线上的运动，以及对应的母线、切点 A、B |
| **几何性质演示** | 实时展示 \|PF₁\| + \|PF₂\| = 常数（椭圆）、\|PF₁\| - \|PF₂\| = 常数（双曲线）等性质 |

### 控制面板

- **▶ / ⟲** — 播放/暂停动画、重置
- **α（半顶角）** — 调节圆锥的半顶角（12° ~ 48°）
- **γ（截面角）** — 调节截面与轴的夹角（5° ~ 85°），决定曲线类型：
  
  - γ > α → **椭圆**
  - γ = α → **抛物线**
  - γ < α → **双曲线**
- **P（点位置）** — 手动调节点 P 在曲线上的位置
- **Speed** — 动画速度

### 自动判别曲线类型

| --- | --- | --- |

| γ > α | 椭圆 | 2个（都在正圆锥内） |
| --- | --- | --- |
| γ = α | 抛物线 | 1个 |
