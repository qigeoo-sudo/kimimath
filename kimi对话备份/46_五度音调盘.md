### 🎻 Cello（大提琴）

plain 复制

```plain
振荡器: sawtooth(主) + sine(-1八度) + triangle(+1八度)
```

- **sawtooth**：弦乐器的弓拉弦产生丰富谐波
- **sine 低八度**：大提琴的低频胸腔共鸣
- **triangle 高八度**：增加一点明亮度，模拟弦的高频泛音
- **lowpass 450Hz**：大提琴是中低频乐器，切掉刺耳高频

### 🪈 Flute（长笛）

plain 复制

```plain
振荡器: sine(主) + triangle(+1八度) + sine(+2八度)
滤波器: bandpass 1800Hz, Q=2.5
颤音: 5.5Hz, 深度 1.2
增益: 0.32（提高，之前太轻）
```

- **sine**：气柱振动产生极纯净的基波
- **triangle 高八度**：长笛的轻微泛音（比弦乐少得多）
- **sine 双高八度**：模拟气息感
- **bandpass 1800Hz**：突出长笛的中高频明亮区
- **增益 0.32**：之前 bandpass Q=8 切掉了太多能量，现在 Q=2.5 + 增益提高

### 🎹 Organ（管风琴）

plain 复制

```plain
振荡器: square(主) + square(-1八度) + sawtooth(基频) + square(+1八度)
滤波器: lowpass 1200Hz, Q=0.3
颤音: 无
```

- **square ×2**：管风琴是"簧片/气柱"发声，奇次谐波极丰富
- **sawtooth**：叠加一点偶次谐波，让声音不那么"方"
- **低八度 square**：模拟脚踏低音管
- **Q=0.3**：管风琴不需要滤波器塑形，让它自然轰鸣
- **无颤音**：管风琴是机械/电子控制，没有自然颤音

### 🎹 Piano（钢琴）——这才是重点

plain 复制

```plain
振荡器: triangle(主) + sawtooth(+1八度) + triangle(-1八度)
滤波器: lowpass 4000Hz, Q=1.2
特殊: 白噪声冲击（琴槌击弦）
```

- **triangle**：比 sine 丰富（有奇次谐波），比 sawtooth 柔和
- **sawtooth 高八度**：钢琴泛音极丰富
- **triangle 低八度**：增加琴体的浑厚感
- **lowpass 4000Hz**：钢琴是全频乐器，保留更多高频
- **白噪声冲击**：每次换音时触发 80ms 的衰减噪声，模拟**琴槌击弦的"咔哒"声**——这是钢琴区别于弦乐最关键的特征

JavaScript 复制

```javascript

// → null.addEventListener(...) → TypeError → 脚本中断
```
