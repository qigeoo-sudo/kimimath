## 数字键盘问题清单

### 1. **✅ 点击外部关闭时丢失数据** — 已确认存在

`document click` 事件处理中，点击 numpad 外部直接关闭键盘，但**没有恢复 input 的原始值**。如果用户输入了表达式但还没确认，数据就丢了。不过看逻辑这是"取消编辑"行为，可能是设计意图，但体验不佳。

### 2. **✅ `safeEval` 中 `e` 被替换为 `Math.E` 导致变量名冲突**

JavaScript 复制

```js
.replace(/e/g, '(' + Math.E + ')')
```

这会把所有 `e` 都替换掉，包括 `Math.sqrt` 中的 `e`（虽然这里没 `e`），以及任何用户可能输入的含 `e` 的表达式。更关键的是，如果表达式中有 `Math.sqrt` 前面已经被替换了，但 `e` 的替换是全局的，会把 `Math.sqrt(2.718...)` 中的 `e` 也替换掉... 实际上 `Math.E` 是数字 `2.718...`，替换后变成 `2.718...`，没有 `e` 字符了，所以不会递归替换。但问题是如果用户想输入科学计数法如 `1e3`，会被替换成 `12.718...3`，这是**严重 bug**。

### 3. **✅ `safeEval` 中 `Math.sqrt` 替换正则有问题**

JavaScript 复制

```js
jsExpr = jsExpr.replace(/Math\.sqrt(\d+(?:\.\d+)?)/g, 'Math.sqrt($1)');
```

这个正则只匹配 `Math.sqrt` 后面直接跟数字的情况。但如果用户输入 `√(3+4)`，替换后变成 `Math.sqrt(3+4)`，正则匹配不到（因为 `(` 不是数字）。然后 `new Function` 执行 `Math.sqrt(3+4)` 会报错，因为 `Math.sqrt` 后面直接跟 `(` 在 JS 中是合法调用，但 `Math.sqrt` 不是 `Math.sqrt(`... 等等，实际上 `Math.sqrt(3+4)` 是**合法的 JS 表达式**！所以这不是问题。但如果用户输入 `√3+4`，替换后是 `Math.sqrt3+4`，正则匹配 `Math.sqrt3` 失败（`3` 是数字但后面有 `+4`），结果是 `Math.sqrt3+4`，`Math.sqrt3` 是 `undefined`，`undefined+4=NaN`。这是**bug**。

### 4. **✅ `showNumPad` 中 `pad.style.display` 截断**

代码中：

JavaScript 复制

```js
updateNumpadDisplay();
pad.sty
```

这里 `pad.sty` 明显被截断了！应该是 `pad.style.display = 'flex';`。这是一个**严重 bug**，会导致键盘无法显示。

### 5. **✅ `buildCurveParams` 中 `input` 实际是 `div` 的注释误导**

注释说"使用 div 替代 input"，但代码实际创建的是 `input` 元素。这不是 bug，但注释和代码不一致。

### 6. **✅ `input.onfocus` 中 `input.blur()` 可能导致闪烁**

快速 blur 在移动端可能仍然触发系统键盘弹出一下再消失，体验不好。

### 7. **✅ 数字键盘缺少 `−`（负号）按钮**

键盘只有 `-`（减号运算符），没有专门的负号/正负号切换按钮。对于输入负数不太方便。

### 8. **✅ 没有 `C`（清空）按钮**

只有 `←`（退格），没有一键清空。

### 9. **✅ `safeEval` 的 `new Function` 安全性**

虽然说是"安全执行"，但 `new Function` 仍然可以执行任意代码。不过在这个封闭环境中风险较低。

### 10. **✅ `showNumPad` 中 `numPadExpr` 初始化**

JavaScript 复制

```js
numPadExpr = String(inputEl.value || '');
```

如果 `inputEl.value` 是数字 `0`，`String(0)` 是 `'0'`，没问题。但如果值是 `undefined` 或 `null`，会转成字符串 `'undefined'` 或 `'null'`。不过 `|| ''` 处理了 falsy 值，但 `0` 也是 falsy，所以如果当前值是 `0`，会变成空字符串！这是**严重 bug**！等等，让我再确认：`inputEl.value` 是字符串属性，所以 `inputEl.value || ''` 中，如果 `value` 是字符串 `'0'`，`'0'` 是 truthy，没问题。但如果值是数字 `0`（通过 JS 直接赋值），`0 || ''` 会变成 `''`。不过 HTML input 的 value 总是字符串，所以应该没问题。

### 11. **✅ `numpadConfirm` 中 `numPadTarget.value = numPadExpr`**

确认后显示的是表达式字符串而不是计算结果。这是设计意图（保留表达式），但用户可能期望看到计算后的数值。

function playPianoTone(freq, duration) {
  const ctx = getAudioCtx();
  const t = ctx.currentTime;
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.type = 'triangle';
  osc.frequency.value = freq;
  gain.gain.setValueAtTime(0, t);
  gain.gain.linearRampToValueAtTime(0.3, t + 0.01);
  gain.gain.exponentialRampToValueAtTime(0.001, t + duration);
  osc.connect(gain);
  gain.connect(ctx.destination);
  osc.start(t);
  osc.stop(t + duration);
}

function paramToNote(paramName, value) {
  const scale = majorScales[paramName];
  if (!scale) return null;
  const minVal = -50, maxVal = 50;
  const ratio = (value - minVal) / (maxVal - minVal);
  const idx = Math.max(0, Math.min(scale.length - 1, Math.round(ratio * (scale.length - 1))));
  return scale[idx];
}

function handleNumpad(ch, type) {
  if (type === 'ok') {
    numpadConfirm();
    return;
  }
  if (type === 'clear') {
    numPadExpr = '';
    updateNumpadDisplay();
    return;
  }
  if (type === 'back') {
    if (numPadExpr.length > 0) {
      numPadExpr = numPadExpr.slice(0, -1);
    }
    updateNumpadDisplay();
    return;
  }
  if (type === 'sign') {
    // 切换正负号：在表达式开头加/减负号
    if (numPadExpr.length === 0) {
      numPadExpr = '-';
    } else if (numPadExpr.startsWith('-')) {
      numPadExpr = numPadExpr.substring(1);
    } else {
      numPadExpr = '-' + numPadExpr;
    }
    updateNumpadDisplay();
    return;
  }
  // 数字、运算符、括号、常量都直接追加
  numPadExpr += ch;
  updateNumpadDisplay();
}

function safeEval(expr) {
  // 安全计算数学表达式
  // 先处理 √ 后面跟括号的情况：√( → Math.sqrt(
  let jsExpr = expr
    .replace(/×/g, '*')
    .replace(/÷/g, '/')
    .replace(/%/g, '/100');

  // 处理 √：√数字 → Math.sqrt(数字)，√( → Math.sqrt(
  jsExpr = jsExpr.replace(/√(\d+(?:\.\d+)?)/g, 'Math.sqrt($1)');
  jsExpr = jsExpr.replace(/√\(/g, 'Math.sqrt(');
  // 处理剩余的 √（后面跟变量等）
  jsExpr = jsExpr.replace(/√/g, 'Math.sqrt');

  // 替换常量（注意：要在其他替换之后，避免干扰）
  jsExpr = jsExpr
    .replace(/π/g, '(' + Math.PI + ')')
    .replace(/(?<![a-zA-Z])e(?![a-zA-Z])/g, '(' + Math.E + ')');

  try {
    const result = new Function('return ' + jsExpr)();
    if (!isFinite(result) || isNaN(result)) return NaN;
    return result;
  } catch (e) {
    return NaN;
  }
}

function getZeroPoint() {
  if (mode === 'RP1') {
    const { a, b } = params;
    if (Math.abs(a) < 0.1) return null;
    return { x: -b / a, y: -b / a };
  } else {
    const [a_re, a_im] = getComplexParam('a');
    const [b_re, b_im] = getComplexParam('b');
    const a_mag_sq = a_re * a_re + a_im * a_im;
    if (a_mag_sq < 1e-6) return null;
    const num_re = b_re * a_re + b_im * a_im;
    const num_im = b_im * a_re - b_re * a_im;
    return { x: -num_re / a_mag_sq, y: -num_im / a_mag_sq };
  }
}

function getSingularityPoint() {
  if (mode === 'RP1') {
    const { c, d } = params;
    if (Math.abs(c) < 0.1) return null;
    return { x: -d / c, y: -d / c };
  } else {
    const [c_re, c_im] = getComplexParam('c');
    const [d_re, d_im] = getComplexParam('d');
    const c_mag_sq = c_re * c_re + c_im * c_im;
    if (c_mag_sq < 1e-6) return null;
    const num_re = d_re * c_re + d_im * c_im;
    const num_im = d_im * c_re - d_re * c_im;
    return { x: -num_re / c_mag_sq, y: -num_im / c_mag_sq };
  }
}

function mobius(z, a, b, c, d) {
  const denom = c * z + d;
  if (Math.abs(denom) < 1e-12) return NaN;
  const result = (a * z + b) / denom;
  if (!isFinite(result) || Math.abs(result) > 1e6) return NaN;
  return result;
}

function mobiusComplex(x, y, a_re, a_im, b_re, b_im, c_re, c_im, d_re, d_im) {
  const num_re = (a_re * x - a_im * y) + b_re;
  const num_im = (a_re * y + a_im * x) + b_im;
  const den_re = (c_re * x - c_im * y) + d_re;
  const den_im = (c_re * y + c_im * x) + d_im;
  const den_sq = den_re * den_re + den_im * den_im;
  if (den_sq < 1e-20) return [NaN, NaN];
  const X = (num_re * den_re + num_im * den_im) / den_sq;
  const Y = (num_im * den_re - num_re * den_im) / den_sq;
  if (!isFinite(X) || !isFinite(Y) || Math.abs(X) > 1e6 || Math.abs(Y) > 1e6) return [NaN, NaN];
  return [X, Y];
}

function findEllipticDomains(u, v, w) {
  const f = (x) => u * x * x * x - v * x + w;
  const roots = [];
  const scanMin = -500, scanMax = 500, step = 0.1;
  let prevX = scanMin, prevY = f(prevX);
  for (let x = scanMin + step; x <= scanMax; x += step) {
    const y = f(x);
    if (prevY === 0) roots.push(prevX);
    else if (y === 0) roots.push(x);
    else if (prevY * y < 0) {
      let lo = prevX, hi = x, mid;
      for (let iter = 0; iter < 25; iter++) {
        mid = (lo + hi) / 2;
        const fm = f(mid);
        if (Math.abs(fm) < 1e-12) break;
        if (f(lo) * fm <= 0) hi = mid; else lo = mid;
      }
      roots.push((lo + hi) / 2);
    }
    prevX = x; prevY = y;
  }
  roots.sort((a, b) => a - b);
  const uniq = [];
  for (const r of roots) {
    if (uniq.length === 0 || Math.abs(r - uniq[uniq.length - 1]) > 1e-5) uniq.push(r);
  }
  const intervals = [];
  const tests = [scanMin, ...uniq, scanMax];
  for (let i = 0; i < tests.length - 1; i++) {
    const mid = (tests[i] + tests[i + 1]) / 2;
    if (f(mid) >= 0) intervals.push([tests[i], tests[i + 1]]);
  }
  return intervals;
}

function generateOriginalPoints() {
  const N = 4000;
  const cp = curveParams[currentCurve];
  let pts = [];

  switch (currentCurve) {
    case 'circle':
      for (let i = 0; i <= N; i++) {
        const t = i * 2 * Math.PI / N;
        pts.push([Math.cos(t), Math.sin(t)]);
      }
      break;
    case 'line': {
      const t = cp.t, s = cp.s;
      const eps = 1e-4;
      for (let i = 0; i <= N; i++) {
        const theta = -Math.PI / 2 + eps + (Math.PI - 2 * eps) * i / N;
        const x = Math.tan(theta);
        pts.push([x, t * x + s]);
      }
      break;
    }
    case 'ellipse': {
      const m = cp.m, n = cp.n;
      for (let i = 0; i <= N; i++) {
        const theta = i * 2 * Math.PI / N;
        pts.push([m * Math.cos(theta), n * Math.sin(theta)]);
      }
      break;
    }
    case 'parabola': {
      const t = cp.t, s = cp.s, r = cp.r;
      const eps = 1e-4;
      for (let i = 0; i <= N; i++) {
        const theta = -Math.PI / 2 + eps + (Math.PI - 2 * eps) * i / N;
        const x = Math.tan(theta);
        pts.push([x, t * x * x + s * x + r]);
      }
      break;
    }
    case 'hyperbola': {
      const m = cp.m, n = cp.n;
      const eps = 1e-4;
      for (let i = 0; i <= N / 2; i++) {
        const theta = -Math.PI / 2 + eps + (Math.PI - 2 * eps) * i / (N / 2);
        pts.push([m / Math.cos(theta), n * Math.tan(theta)]);
      }
      for (let i = 0; i <= N / 2; i++) {
        const theta = Math.PI / 2 + eps + (Math.PI - 2 * eps) * i / (N / 2);
        pts.push([m / Math.cos(theta), n * Math.tan(theta)]);
      }
      break;
    }
    case 'elliptic': {
      const u = cp.u, v = cp.v, w = cp.w;
      const intervals = findEllipticDomains(u, v, w);
      if (intervals.length === 0) break;
      const ptsPerInterval = Math.max(80, Math.floor(N / intervals.length));
      for (const [xa, xb] of intervals) {
        for (let i = 0; i <= ptsPerInterval; i++) {
          const x = xa + (xb - xa) * i / ptsPerInterval;
          const rhs = u * x * x * x - v * x + w;
          if (rhs >= 0) pts.push([x, Math.sqrt(rhs)]);
        }
      }
      for (let idx = intervals.length - 1; idx >= 0; idx--) {
        const [xa, xb] = intervals[idx];
        for (let i = ptsPerInterval; i >= 0; i--) {
          const x = xa + (xb - xa) * i / ptsPerInterval;
          const rhs = u * x * x * x - v * x + w;
          if (rhs >= 0) pts.push([x, -Math.sqrt(rhs)]);
        }
      }
      break;
    }
  }
  return pts;
}

function drawCurvePath(pts, color, width, dash, usePhaseColor) {
  ctx.lineWidth = width;
  ctx.setLineDash(dash ? [6, 4] : []);

  let valid = [];
  for (let i = 0; i < pts.length; i++) {
    const [x, y] = pts[i];
    if (isFinite(x) && isFinite(y)) {
      valid.push({ x, y, idx: i });
    }
  }
  if (valid.length < 2) return;

  const MAX_JUMP = 250;

  let segments = [];
  let current = [valid[0]];
  for (let i = 1; i < valid.length; i++) {
    const prev = valid[i - 1];
    const curr = valid[i];
    let shouldBreak = false;
    if (curr.idx !== prev.idx + 1) {
      shouldBreak = true;
    } else {
      const dx = toCanvasX(curr.x) - toCanvasX(prev.x);
      const dy = toCanvasY(curr.y) - toCanvasY(prev.y);
      if (Math.sqrt(dx * dx + dy * dy) > MAX_JUMP) shouldBreak = true;
    }
    if (shouldBreak) {
      if (current.length > 1) segments.push(current);
      current = [curr];
    } else {
      current.push(curr);
    }
  }
  if (current.length > 1) segments.push(current);

  function phaseToHue(x, y) {
    const angle = Math.atan2(y, x);
    return ((angle + Math.PI) / (2 * Math.PI)) * 360;
  }

  for (let seg of segments) {
    if (usePhaseColor && mode === 'CP1') {
      for (let i = 0; i < seg.length - 1; i++) {
        const cx1 = toCanvasX(seg[i].x);
        const cy1 = toCanvasY(seg[i].y);
        const cx2 = toCanvasX(seg[i + 1].x);
        const cy2 = toCanvasY(seg[i + 1].y);
        const hue = phaseToHue(seg[i].x, seg[i].y);
        ctx.strokeStyle = 'hsl(' + hue.toFixed(1) + ', 85%, 50%)';
        ctx.beginPath();
        ctx.moveTo(cx1, cy1);
        ctx.lineTo(cx2, cy2);
        ctx.stroke();
      }
    } else {
      ctx.strokeStyle = color;
      ctx.beginPath();
      for (let i = 0; i < seg.length; i++) {
        const cx = toCanvasX(seg[i].x);
        const cy = toCanvasY(seg[i].y);
        if (i === 0) ctx.moveTo(cx, cy);
        else ctx.lineTo(cx, cy);
      }
      ctx.stroke();
    }
  }
}
