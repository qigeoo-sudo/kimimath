   - RP² 模式：保持当前，两个独立的实 Möbius 变换（X 和 Y 分别变换）
   - CP² 模式：将点 (x,y) 视为复数 z = x + iy，应用复 Möbius 变换 w = (a·z + b) / (c·z + d)，其中 a,b,c,d 是复数。但这样需要 8 个参数。

   这样只需要 4 个实参数，但变换是复的。原始曲线是单位圆 |z|=1（即 x²+y²=1，和当前一样）。让我验证一下：
   
   - RP²: X = (ax+b)/(cx+d), Y = (ay+b)/(cy+d) — 两个独立的实分式线性变换
   - CP²: z = x+iy, w = (az+b)/(cz+d), 然后 X = Re(w), Y = Im(w)
   
   这确实展示了不同的行为。在 RP² 中，x 和 y 是独立变换的；在 CP² 中，x 和 y 通过复数耦合在一起。例如，当 a=1,b=0,c=0,d=1 时，两种模式都是恒等变换。
   当 a=2,b=0,c=0,d=1 时：
   
   - RP²: X=2x, Y=2y，圆变成半径2的圆
   - CP²: w=2z, X=2x, Y=2y，也是半径2的圆
   
   但当 c≠0 时：
   
   - RP²: X=(ax+b)/(cx+d), Y=(ay+b)/(cy+d)，x和y独立映射
   - CP²: w=(az+b)/(cz+d)，这是复平面上的圆到圆的映射（Möbius 变换保圆）
   
   这很有教育意义！在 CP² 模式下，单位圆映射后仍然是圆（或直线）；在 RP² 模式下，一般不是圆。所以我的实现计划：
   
   1. 添加一个切换按钮 "RP² / CP²"
   2. RP² 模式：当前逻辑
   3. CP² 模式：z = x+iy, w = (a*z+b)/(c*z+d), X=Re(w), Y=Im(w)
   4. 由于 a,b,c,d 是实数，复共轭会简化，但仍然是复变换。
