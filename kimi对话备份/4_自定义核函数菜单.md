## 为什么不能只用留数判断

留数定理给周期平行四边形边界一个标量约束：∮ = 2πi·ΣRes，而周期性使对边积分抵消，故 ΣRes = 0。

- **单极点**：主部只有一项 c₋₁z⁻¹，而它恰好就是留数本身。约束 c₋₁ = 0 把主部整个钉死了 ⇒ 不存在。
- **n ≥ 2 阶极点**：主部有 n 个自由系数，约束只杀掉 z⁻¹ 系数那一个，还剩 n−1 维自由度 ⇒ 解存在（这就是环面上的 Mittag–Leffler 定理）。

## 1/u³ 确实存在，而且就是 −℘′/2

function liCustomInfo(){
  const f = getCurrentFunc();
  if(f.hasBranchCut) return ['✗ 多值（分支点）','—','刘维尔前提不满足','判定不适用','自定义表达式含 ln/log/sqrt 类结构。'];
  const pts = f.singularityPoints;
  const bad = pts.filter(p => p.type === 'essential' || p.type === 'branch');
  if(bad.length) return ['✗ 非整（本性奇点）','任意邻域无界（Picard 型）','不适用','✗ 不能','自动探测到本性奇点。'];
  if(pts.length) return ['✗ 非整（' + pts.length + ' 个极点）','∞ 处是否有界需具体分析','不适用（圈内含奇点即被拦截）','✗ 不能','留数定理菜单可验证留数和。'];
  return ['✓ 整（探测范围内）','未知——有界性不可自动判定','✓ 可用（探测范围内）','未知——需分析 ∞ 处行为','在 Taylor 菜单实测各阶 cₙ 再作判断。'];
}
