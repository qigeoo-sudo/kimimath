# **第1章 交比的复数生命——莫比乌斯变换**

> **核心问题：如果把四个共线点的交比放到复平面上，会发生什么神奇的事情？**

在第一本书里，我们发现了交比这个"射影宝藏"——四个共线点的交比在透视投影下保持不变。但那时我们只在普通的实数直线上计算交比。现在，让我们把视野扩大一步：如果把整个几何舞台搬到**复数平面**上，交比会展现出怎样的新生命？复数不仅仅是"负数的平方根"那么简单。当我们把复数看作平面上的点时，加、减、乘、除都有了奇妙的几何意义。而交比——这个由四个点决定的"比例之比"——在复数世界里将化身为一类极其优美的变换：**莫比乌斯变换**。

## **1.1 复数：从代数到几何的跃迁**

+-----------------------------------------------------------------------+
| **数学史故事** |
| |
| 1799年，挪威测量员卡斯帕尔·韦塞尔（Caspar Wessel）第一次把复数画成 |
| 平面上的点。但直到1831年，高斯（Carl Friedrich Gauss）才正式提出"复数 |
| 平面"（complex plane）的概念。高斯说：每一个复数 z = a + bi 都对应平面上|
| 的一个点 (a, b)。这一简单的对应，彻底改变了人类对"数"的理解。 |
+-----------------------------------------------------------------------+让我们快速回顾复数的基本面貌。一个复数写成：**z = a + bi**其中 a 是实部，b 是虚部，i 是虚数单位，满足 i² = -1。在复平面上，横轴是实轴，纵轴是虚轴。复数 z = a + bi 就坐在坐标 (a, b) 的位置。**复数运算的几何意义**复数的加减法很简单：就像向量的平移。z₁ + z₂ 就是把两个向量首尾相接。真正神奇的是**乘法和除法**。如果我们把复数写成极坐标形式：**z = r(cos θ + i sin θ) = r · e^(iθ)**其中 r 是模长（到原点的距离），θ 是辐角（与正实轴的夹角）。那么两个复数相乘，就是**模长相乘，辐角相加**：z₁ · z₂ = r₁r₂ · e^(i(θ₁+θ₂))这意味着：**乘以复数，就是旋转加缩放！**例如，乘以 i（即 e^(iπ/2)）相当于把复平面上的每个点逆时针旋转 90°。乘以 2（即 2e^(i0)）相当于放大两倍。+-----------------------------------------------------------------------+

## **1.2 复平面上的四种"变形"**

在复平面上，有四种最基本的"变形"（数学家称之为**变换**）。它们看起来简单，但组合起来将产生惊人的力量。**第一种：平移****z → z + b**其中 b 是一个固定的复数。这相当于把整个复平面上的每个点都向 b 的方向移动 |b| 的距离。**第二种：旋转****z → e^(iθ) · z**把每个点绕原点逆时针旋转角度 θ。如果 θ = 90°，就是乘以 i；如果 θ = 180°，就是乘以 -1。**第三种：缩放（位似）****z → a · z** （a 是正实数）把每个点到原点的距离放大 a 倍。如果 a = 2，所有图形都放大两倍；如果 a = 1/2，就缩小一半。**第四种：反演****z → 1/z̄** （或等价地，z → 1/z 后再做反射）反演是最神秘的一种变换。它把复平面上每个点 z 送到 1/z 的位置。

- 模长为 1 的点（单位圆上的点）保持不动。
- 模长小于 1 的点（单位圆内部）被"翻"到外部，且越靠近原点的点被翻得越远。
- 模长大于 1 的点（单位圆外部）被"翻"到内部。

反演就像一面"哈哈镜"：它把无穷远点"拉"到原点，又把原点"推"向无穷远。+-----------------------------------------------------------------------+

## **1.3 莫比乌斯变换：四种变形的"合体"**

+-----------------------------------------------------------------------+
| **数学史故事** |
| |
| 奥古斯特·费迪南德·莫比乌斯（August Ferdinand Möbius），1790–1868， |
| 德国数学家和天文学家。他在1855年研究射影几何时，发现了一类极其优美的 |
| 变换。这类变换不仅能做平移、旋转、缩放，还能做反演——它们就是今天我们 |
| 要讲的"莫比乌斯变换"。有趣的是，莫比乌斯带（那个只有一个面的纸带）也是 |
| 他的发明，我们将在第7章拓扑学中再次遇见它。 |
+-----------------------------------------------------------------------+莫比乌斯变换的公式看起来有点复杂，但它其实是刚才四种基本变换的"合体"：**z → (az + b) / (cz + d)**其中 a, b, c, d 是复数，且满足 **ad - bc ≠ 0**。这个条件 ad - bc ≠ 0 很重要。如果 ad - bc = 0，那么分子和分母成比例，整个变换会退化成一个常数（把所有点都送到同一个点），那就不是"变形"而是"压扁"了。**为什么叫"四种变形的合体"？**我们可以把莫比乌斯变换分解成一系列简单步骤：

1. **z → cz + d**：先做旋转+缩放（乘以 c），再平移（加 d）
2. **z → 1/z**：反演（这是最关键的一步！）
3. **z → (ad-bc)/c · z + a/c**：再做一次旋转+缩放+平移

也就是说，**任何一个莫比乌斯变换都可以写成：平移 → 旋转缩放 → 反演 → 旋转缩放 → 平移** 的组合！这就像一个复杂的舞蹈动作，其实是由"走、转、翻、转、走"几个基本步组合而成的。

## **1.4 圆保持定理：圆和直线的统一**

莫比乌斯变换最神奇的性质，是它对"圆"的态度。在普通几何中，圆和直线是两类不同的图形。但在复平面上，如果我们把**直线看作"半径无穷大的圆"**（即经过无穷远点的圆），那么莫比乌斯变换有一个惊人的性质：

> **圆保持定理**：莫比乌斯变换把圆变成圆，把直线变成直线或圆。

换句话说，在莫比乌斯变换的"眼睛"里，圆和直线是同一类东西！这与我们在第一本书中学到的射影几何思想完美呼应——在射影几何中，抛物线、椭圆、双曲线也是"同一种东西"。**直觉解释**为什么反演能保持"圆性"？让我们看一个例子。考虑实轴上的单位圆：|z| = 1。在反演 z → 1/z 下，单位圆上的点 z = e^(iθ) 被送到 1/e^(iθ) = e^(-iθ)，仍然在单位圆上。所以单位圆保持不动。再考虑一条不经过原点的直线，比如 Re(z) = 1（即 x = 1）。这条直线上的点可以写成 z = 1 + iy。经过反演：1/z = 1/(1 + iy) = (1 - iy)/(1 + y²) = 1/(1+y²) - i·y/(1+y²)设 u = 1/(1+y²)，v = -y/(1+y²)。可以验证：(u - 1/2)² + v² = (1/4)也就是说，反演把直线 x = 1 变成了一个圆——一个经过原点的圆！[media/mobius_circle.png](media/mobius_circle.png){width="5.0in" height="3.0in"}*图1-1：反演变换把直线变成圆。左图为原直线，右图为反演后的圆。*

## **1.5 交比在莫比乌斯变换下的不变性**

现在，让我们回到本章的核心问题：**交比在复平面上会发生什么？**在第一本书中，我们定义了四个共线实点 A, B, C, D 的交比：**H(A,B;C,D) = (AC/BC) / (AD/BD)**（其中 AC, BC, AD, BD 均为有向距离，需考虑正负号）当这些点位于复平面上时，交比的定义完全一样，只是距离变成了**复数距离**（即复数之差的模）。但更深刻的视角是：

> **交比定理**：如果四个点 z₁, z₂, z₃, z₄ 在复平面上，它们的交比
> **(z₁ - z₃)(z₂ - z₄) / ((z₂ - z₃)(z₁ - z₄))**
> 在莫比乌斯变换下保持不变。

这正是第一本书中"交比在射影变换下不变"的复数版本！莫比乌斯变换就是复平面上的"射影变换"，而交比就是它的"不变量"。+-----------------------------------------------------------------------+
| **★ 选读：交比不变性的证明思路** |
| |
| 要证明交比在莫比乌斯变换下不变，只需验证它在四种基本变换下分别不变。 |
| 平移和旋转缩放显然不改变交比（它们只是改变了坐标系，没有改变点之间的 |
| 相对关系）。最难的是反演 z → 1/z。 |
| |
| 将四个点取反演后的像 1/z₁, 1/z₂, 1/z₃, 1/z₄，直接代入交比公式，经过代数 |
| 运算可以发现分子分母恰好抵消，交比值与原交比值相等。 |
| |
| 本部分为选读内容，初学者可以跳过，不影响后续理解。 |

## **1.6 从交比到莫比乌斯变换：一个统一的视角**

让我们把本章的线索串起来：

1. **交比**是射影几何的灵魂不变量（第一本书）
2. **复数**让几何运算有了代数翅膀（本章1.1）
3. **莫比乌斯变换**是复平面上的射影变换，它保持交比不变（本章1.5）
4. **圆保持定理**告诉我们，在莫比乌斯变换眼中，圆和直线是一回事（本章1.4）

这意味着：**从复数的视角看，射影几何变得更加统一和优美**。我们不再需要区分圆和直线，不再需要区分椭圆、抛物线、双曲线——在莫比乌斯变换的"魔法"下，它们都是同一个数学对象的不同面貌。在下一章，我们将引入更强大的代数工具——**矩阵**——来重新描述射影变换。你会发现，莫比乌斯变换的公式 z → (az+b)/(cz+d) 与 2×2 矩阵 [[a,b],[c,d]] 有着深刻的对应关系。而交比的不变性，也将在矩阵的语言中获得更简洁的表达。
