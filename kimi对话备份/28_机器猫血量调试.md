问题在于 **`int` 溢出**。

## 错误原因

你的 `r` 设成了 `2147483647`（`INT_MAX`），而 `checkmate` 里的 `mi` 是 `int`。当 `mid` 很大时，如果遇到**营地（正数）**，`mi += a[i]` 会**整数溢出**变成负数，导致 `mi <= 0` 误判为不可行。例如：

- `mid = 2147483000`，遇到 `a[i] = 1000`
- `mi += 1000` 溢出变成负数
- 函数返回 `false`，二分误以为血量不够，继续往右找
- 最终 `l` 甚至可能发生溢出，导致答案错误

## 修正方法

**把 `checkmate` 里的 `mi` 改成 `long long`：**

cpp 复制

```cpp
bool checkmate(int mi){
    long long now = mi;  // ← 改成 long long
    for(int i = 1; i <= n; i++){
        now += a[i];
        if(now <= 0) return false;
    }
    return true;
}
```

**同时把 `r` 的范围缩小**（其实不缩也能过，但更安全、更快）：最大需要的初始血量不会超过 `100000 × 1000 + 1 = 100000001`，所以 `r` 没必要开到 `INT_MAX`。

## 完整修正代码

cpp 复制

```cpp
#include<bits/stdc++.h>
using namespace std;

int a[100001];
int n;

bool checkmate(int mi){
    long long now = mi;  // 防溢出
    for(int i = 1; i <= n; i++){
        now += a[i];
        if(now <= 0) return false;
    }
    return true;
}

int main(){
    cin >> n;
    for(int i = 1; i <= n; i++) cin >> a[i];
    
    int l = 1, r = 1000000001;  // 足够大的范围，避免溢出风险
    while(l <= r){
        int mid = l + (r - l) / 2;
        if(checkmate(mid)) r = mid - 1;
        else l = mid + 1;
    }
    cout << l;
    
    return 0;
}
```
