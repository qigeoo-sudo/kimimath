## 图里的数学结构

图 (a)(b) 画的是 w=sα+1 的黎曼曲面，参数化方式很经典：

- 令 s=reiθ ，底平面上取极坐标 (rcosθ, rsinθ)
- 高度方向画 ∣w∣ （或 Rew ），关键点是 **θ 不限制在 [0,2π) ，而是连续绕 n 圈**： θ∈[0, 2πn]
- 这样得到的不是 n 个分离的面片，而是**一整块连续的螺旋坡面**（类似螺旋楼梯），绕完 n 圈后首尾缝合——这才是真正的黎曼曲面。绕原点每转一圈就"升一层"，正对应图里 (a) 两圈两层、(b) 三圈三层的样子
- 原点是枝点（branch point），所有叶在这里汇合，图中中心那个"漩涡"就是它

所以换个 n 只需要改 θ 的绕行圈数， n=2 到 n=13 是同一个公式，13 叶就是一座 13 层的螺旋坡，完全不难。甚至以后想加分情形（比如图 b 的 s4/3 那种"分子>1"）也只是改个指数。

## +1 的真正来源

这张图出自一篇分数阶微积分方向的论文（*Abstract and Applied Analysis*）， P(sα) 是**分数阶系统的特征多项式**。研究分数阶系统稳定性时，要解形如 sα+1=0(α=1/2, 4/3, …) 的特征方程。麻烦在于： α 是分数时， sα 是**多值函数**——同一个 s 对应好几个 sα 的值，没法在普通复平面上讨论"根在哪里"。解决办法就是把定义域升级成黎曼曲面：让 s 绕原点转一圈不回到原面，而是"爬到下一叶"，转满 n 圈才回来。这样多值函数就变成了曲面上的单值函数，方程的根也能正常画了。所以图注写的是 " P(sα)=s1/2+1 有两叶"——意思是这个函数的定义域黎曼曲面是两叶的，叶数来自 s1/2 的分母 2，+1 只是原论文里那道具体特征方程留下的常数项。

function buildPathTable(n){

  pathPts.push(_pv.clone());
  for(let i=1;i<=PT_M;i++){
    pathPoint(i/PT_M, n, _v);
    pathCum[i] = pathCum[i-1] + _v.distanceTo(_pv);
    _pv.copy(_v); pathPts.push(_v.clone());
  }
  pathLen = pathCum[PT_M];
}
function samplePath(dist, out){
  dist = ((dist % pathLen) + pathLen) % pathLen;
  // binary search
  let lo=0, hi=PT_M;
  while(lo<hi){ const mid=(lo+hi)>>1; if(pathCum[mid]<dist) lo=mid+1; else hi=mid; }
  const i = Math.max(1, lo);
  const f = (dist - pathCum[i-1]) / Math.max(1e-9, pathCum[i]-pathCum[i-1]);
  out.copy(pathPts[i-1]).lerp(pathPts[i], f);
  return out;
}
