绕一个支点（作用1 或 2）→ √Δc 悄悄变号，x/2 + √Δc 与 x/2 − √Δc 互换 → 两根对换 → 开平方（判别式平方根的符号翻转）。

绕两个支点（1∘2 或 2∘1）→ √Δc 变号两次、复原，但立方根辐角已转 ±120° → 三根循环 → 开立方（立方根的辐角旋转）。

不绕（原地打转）→ 所有根式不变 → 恒等 e。

S₃ = 恒等 + 3 个对换 + 2 个三循环；A₃ = {e, (123), (132)}。求根公式的结构 = 先开平方，再开立方。

可解群链　S₃ ⊃ A₃ ⊃ {e}

S₃/A₃ ≅ Z₂：Z₂ 就是"奇偶二分"——A₃ 是偶置换（恒等、3-循环），三个对换是奇置换。两类正好对应 √Δc 的两个符号，即开平方那一步。

A₃/{e} ≅ Z₃：恒等与两个三循环构成三档循环，正好对应立方根辐角的 0°、±120°，即开立方那一步。

每一级商群都是循环群，所以 S₃ 是可解群；卡尔达诺公式"先 √ 后 ∛"的嵌套，正是这条链的几何实现。四次方程的 S₄ 仍有这样的链（故四次可解）；五次方程的 A₅ 是单群，链到此中断——一般五次方程无根式解，伽罗瓦理论的入口就在这里。
